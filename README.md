# WYDPEDIA — Wiki de WYD | Vikings

A **WYDPEDIA** é uma enciclopédia digital desenvolvida para reunir, organizar e disponibilizar informações, tutoriais e conteúdos relacionados ao universo do jogo **With Your Destiny (WYD)**, com foco na comunidade do servidor Vikings.

O projeto foi criado com o objetivo de facilitar o acesso ao conhecimento do jogo, oferecendo uma plataforma intuitiva, organizada e de fácil navegação, reunindo informações importantes para jogadores iniciantes e experientes.

### ⚔️ Funcionalidades

- **Centralização de informações:** tutoriais, dicas e conteúdos do jogo em um único lugar.
- **Organização por categorias:** conteúdos separados para facilitar a localização das informações.
- **Pesquisa integrada:** busca rápida por termos e conteúdos específicos.
- **Interface personalizada:** identidade visual inspirada na temática nórdica e Viking.
- **Navegação simplificada:** acesso rápido às informações por meio de uma interface intuitiva.
- **Checklist de progresso:** acompanhamento de tarefas e etapas de determinados tutoriais.

### 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage

### 🎯 Objetivo

Construir uma base de conhecimento colaborativa e continuamente atualizada, facilitando o compartilhamento de informações e contribuindo para a experiência da comunidade WYD.

### 📌 Sobre o projeto

A WYDPEDIA é um projeto independente, desenvolvido com foco na comunidade de jogadores de WYD. Seu conteúdo poderá receber atualizações, melhorias e novas funcionalidades conforme a evolução do projeto.
